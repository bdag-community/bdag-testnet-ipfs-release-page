# Contributing to the BDAG Testnet release page

This repository publishes release information for BDAG Community Testnet, chain ID 1043. Visit the [Community Testnet guide](https://bdag.community/testnet) for current network details.

Fork the repository and open a pull request to `develop`. Use the README to run the page, metadata and signature checks locally. Preserve signed release records and keep private operator material out of pull requests. Submit node software changes to the [component repository](https://github.com/orgs/bdag-community/repositories) that owns the code.

Francois (`@franco-is`) and Jeremy (`@strattice`) review changes and promote reviewed contributions from `develop` to `main`. The existing `testnet` branch publishes the operator-qualified Pages release information separately.

For a security issue, follow [SECURITY.md](SECURITY.md).
